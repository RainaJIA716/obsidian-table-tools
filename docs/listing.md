## 短描述（自动从 manifest 带入，140 字符）
Add row numbers beside any Markdown table, give it an editable caption and footnote stored in the note, and copy it as an image or Markdown.

## 长描述（≤1000 字符，实际 812）
Markdown tables in Obsidian have no row numbers, nowhere to put a caption, and no clean way to hand one to someone else. Table Tools adds all three without touching the table's Markdown.

Row numbers are drawn in the gutter beside the table, so they renumber themselves as you add and delete rows and never enter your source.

Click above or below a table to add a caption or a footnote. Both are stored in the note as ordinary Obsidian comments, hidden in Reading view and Live Preview. Your note stays readable, and the table stays valid Markdown, with the plugin disabled.

Hovering a table reveals two buttons: copy it as a PNG rendered in your current theme, or as a clean Markdown table with the caption and footnote attached.

The interface follows Obsidian's own language setting.
